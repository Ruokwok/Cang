# 项目结构与入口

> 返回 [文档索引](README.md)

## 要点
- 一个文件一个类，`class` 起到文件末尾都是类体
- 入口是类中的 `static void main(String[] args)` 或无参 `static void main()`（并存时优先前者）；类体只放字段/方法/构造
- class 之前只允许 namespace / import / 全局函数 / 注释
- 分号可省略（for 三段除外）；# 单行与 #* *# 多行注释
- 推荐的目录结构：stdlib / src / test 布局


Cang 使用「**全局函数在前，一个 class 收尾**」的文件结构约定，程序入口是类中的 `static void main`：

```cang
# class 之前只允许 namespace、import、全局函数和注释
func int add(int a, int b) {
    return a + b
}

# 一个文件一个类；class 起到文件末尾都是类体
class Main
    static func void main(String[] args) {
        Stdout.println(add(1, 2))
    }
```

### 2.1 class 之前的内容

`class` 之前可以出现：

- `namespace` 声明；
- `import` 声明；
- 全局 `func` 函数定义；
- 单行或多行注释；
- 空白行。

**一个文件一个类**：第二个 `class` 报 `Only one class per file`。

**类体只放声明**：字段、`init`/`_init` 构造方法、实例/静态方法；直接写 `if` 等语句报
`statements are not allowed in the class body`——逻辑代码放在 `static void main` 或方法内。

**类前禁止逻辑语句**：一旦文件里有 class，出现在 class **之前**的可执行语句会在编译期报错
（`statements are not allowed before the class`）；无类程序不受此限制。

**无类程序**：最小示例可以完全不写 `class`——顶层语句直接构成 main（全局函数同样可用）：

```cang
Stdout.println("Hello, Cang!")     # 不需要 class
```

**同名类消歧**：不同命名空间下的两个同名类可以同时 import，但简单类名只在唯一时可用；冲突时必须写全限定名（命名空间中的 `/` 换成 `_`）：

```cang
import a/util/Logger
import b/util/Logger

class Main
    static func void main(String[] args) {
        Stdout.println(a_util_Logger.who())   # 全限定名
        Stdout.println(b_util_Logger.who())
        Stdout.println(Logger.who())          # 编译错误：Class 'Logger' is ambiguous across namespaces
    }
```

**import 别名（`as`）**：`import <路径> as <别名>` 后可用别名代替类名。`as` **不是关键字**——只在 `import` 行内起作用，代码里 `as` 仍可作变量/函数名：

```cang
import cc/ruok/Server as RuokServer
import cang/lang/Dict as Map

class Main
    static func void main(String[] args) {
        var s = new RuokServer("box")               # new 用别名
        Stdout.println(RuokServer.kind())           # 静态调用用别名
        RuokServer t = new RuokServer()             # 类型注解用别名
        Map<String, int> d = new Map<String, int>() # 泛型同样支持
        int as = 5                                  # as 仍是普通标识符
        Stdout.println(s.name() + t.name() + d.size() + as)
    }
```

- 别名与已有类名冲突时编译报错（`Import alias '...' conflicts with class '...'`），换一个别名即可；
- 别名是引入类的另一个名字，不会生成新类型：`s like RuokServer` 等类型判断同样生效；
- 别名也是消歧手段之一——两个同名类可分别 `as A` / `as B`。

**类名解析顺序**：代码里引用一个类名时按序查找——

1. 文件中的**显式 `import`**（最优先，推荐跨目录时显式书写）；
2. **同命名空间兄弟文件**（主文件命名空间优先，其次已加载文件的命名空间）；
3. 标准库 `cang/lang/` 下的同名文件；
4. 标准库 `cang/io/` 下的同名文件；
5. 标准库 `cang/util/json/` 下的同名文件；
6. 都没有 → 报错（`Unknown class` / 使用处的编译错误）。

自动查找按“引用了哪些类型”递归进行，因此 `Error`、`Dict`、`List`、`File`、`Scanner`、`Coroutine`、`Field`、`Json`、`JsonValue` 等标准库类通常**可以不写 import**；显式 import 仍然有效且优先。类型关键字如 `int`/`String` 内建，不参与查找。

### 2.2 语句分号

普通语句末尾分号可省略：

```cang
int x = 1
Stdout.println(x)
```

也可以使用分号：

```cang
int x = 1;
Stdout.println(x);
```

`for` 循环的三个组成部分之间必须使用分号：

```cang
for (int i = 0; i < 10; i++) {
    Stdout.println(i)
}
```

### 2.3 注释

单行注释：

```cang
# 这是单行注释
```

多行注释：

```cang
#*
这是多行注释。
可以包含多行内容。
*#
```
