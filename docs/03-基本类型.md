# 基本类型

> 返回 [文档索引](README.md)

## 要点
- byte/int/long/float/double/bool 六种值类型
- 整数与浮点字面量增强：下划线分隔、进制前缀、L/F 后缀
- null 属于引用类型；值类型不可为 null


当前支持的基本类型：

| 类型 | 说明 |
|---|---|
| `byte` | 8 位整数 |
| `int` | 32 位整数 |
| `long` | 64 位整数 |
| `float` | 单精度浮点数 |
| `double` | 双精度浮点数 |
| `bool` | 布尔值 |
| `string` | Cang 的字符串基本类型，内部语义为 `str` |
| `String` | 引用类型字符串对象 |
| `var` | 根据初始化表达式推导类型 |
| `Void` | 函数类型中的无返回值包装名称 |

### 3.1 整数

```cang
byte b = 127
int i = 123
long l = 123456789L
```

数字可以使用下划线分隔：

```cang
int million = 1_000_000
```

支持十六进制和二进制：

```cang
int hex = 0xFF
int binary = 0b1010
```

### 3.2 浮点数

```cang
float f = 1.5f
double d = 3.1415926
```

常用后缀：

- `f/F`：float
- `d/D`：double
- `l/L`：long
- `i/I`：int
- `b/B`：byte

### 3.3 布尔值

```cang
bool enabled = true
bool finished = false
```

### 3.4 null

引用类型可以使用 `null`：

```cang
String text = null
Point point = null
```

`var` 无法从 `null` 推导类型：

```cang
var value = null       # 编译错误
String value = null    # 合法
```
