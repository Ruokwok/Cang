# 基本类型

> 返回 [文档索引](README.md)

## 要点
- byte/int/long/float/double/bool 六种值类型
- 整数与浮点字面量增强：下划线分隔、进制前缀、L/F 后缀
- null 属于引用类型；值类型不可为 null


当前支持的值类型：

| 类型 | 说明 |
|---|---|
| `byte` | 8 位整数 |
| `int` | 32 位整数 |
| `long` | 64 位整数 |
| `float` | 单精度浮点数 |
| `double` | 双精度浮点数 |
| `bool` | 布尔值 |

另外三种常见写法不属于值类型：

- `String`：引用类型字符串对象（见 [字符串](04-字符串.md)）；
- `var`：局部变量类型推导关键字，不是运行时类型；
- `Void`：函数类型中的无返回值包装名，如 `Function<Void, int>`。

### 3.1 整数

```cang
byte b = 127
int i = 123
long l = 123456789L
```

数字可以使用下划线分隔：

```cang
int million = 1_000_000
```

支持十六进制和二进制：

```cang
int hex = 0xFF
int binary = 0b1010
```

### 3.2 浮点数

```cang
float f = 1.5f
double d = 3.1415926
```

常用后缀：

- `f/F`：float
- `d/D`：double
- `l/L`：long
- `i/I`：int
- `b/B`：byte

### 3.3 布尔值

```cang
bool enabled = true
bool finished = false
```

### 3.4 null

引用类型可以使用 `null`：

```cang
String text = null
Point point = null
```

`var` 无法从 `null` 推导类型：

```cang
var value = null       # 编译错误
String value = null    # 合法
```
