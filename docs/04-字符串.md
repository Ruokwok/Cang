# 字符串 string 与 String

> 返回 [文档索引](README.md)

## 要点
- str 是基本类型（栈上字符序列），String 是引用类型
- String 支持显式转换与装箱；== 对 String 按内容比较
- 字符串常量池与分配语义
- 支持 `\n`/`\t` 等转义；未知转义是编译错误


Cang 区分基本字符串类型和引用字符串类型。

### 4.1 string

`string` 是基本字符串类型，使用单引号：

```cang
string name = 'Cang'
var text = 'hello'
```

特点：

- 单引号字面量类型为 `string`/`str`；
- 没有对象方法；
- 适合短文本和基础字符串值；
- 不允许直接调用 `length()`、`substring()` 等对象方法。

### 4.2 String

`String` 是 `cang/lang/String` 引用类型对象，双引号和反引号字面量属于 `String`：

```cang
String name = "Cang"
String paragraph = `第一行
第二行`
```

反引号适合多行字符串。

### 4.3 显式转换和装箱

```cang
string raw = 'hello'
String boxed = new String(raw)

string numberText = string(123)
String numberObject = String(123)
```

`string` 与 `String` 不进行隐式互转。

### 4.4 字符串比较

两种字符串都支持 `==` 和 `!=`：

```cang
string a = 'hello'
String b = "hello"

bool same = a == b
bool different = a != "world"
```

底层比较使用字符串内容比较。

### 4.5 字符串常量池

字符串字面量由编译器放入 LLVM 全局常量区，相同文本可以复用常量。字符串是不可变的，拼接会生成新的字符串缓冲区。

### 4.6 转义序列

**双引号 `"..."` 与单引号 `'...'`** 共用同一套转义：

| 转义 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\"` | 双引号（单引号串中同样可用） |
| `\'` | 单引号 |
| `\0` | 空字节 |
| `\` + 行尾 | 续行（吞掉换行与缩进继续当前字符串） |

```cang
Stdout.println("tab:[a\tb]")
Stdout.println("换行：\n下一行")
Stdout.println("路径：C:\\tmp\\x")
string t = 'a\tb'          # 单引号串同样支持转义
```

**反引号 `` `...` ``（多行字符串）** 支持 `\n`、`\t`、`\r`、`\\`、`` \` `` 与续行；
内容本身可直接写真换行。集合略小：**`\"` 在反引号串中是编译错误**
（`"` 无需转义，直接写即可）。

注意：

- **未知转义一律编译错误**（如 `\d`、`\x`、反引号内的 `\"`），不会静默丢掉反斜杠；
- 反引号串**不是**字节级 raw——`\n` 仍会解析成换行，它只是可跨行的字符串。
