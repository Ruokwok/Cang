# 字符串 String

> 返回 [文档索引](README.md)

## 要点
- 只有一种字符串类型 `String`（引用类型）
- `"..."`、`'...'`、`` `...` `` 三种字面量写法，类型均为 `String`
- `==` 对 `String` 按内容比较
- 字符串常量池与分配语义
- 支持 `\n`/`\t` 等转义；未知转义是编译错误

Cang 只有 `String` 一种字符串类型（`cang/lang/String` 引用类型对象），没有独立的基本字符串类型。

### 4.1 字面量

三种写法的类型都是 `String`：

```cang
String name = "Cang"
String shortName = 'Cang'
String paragraph = `第一行
第二行`
```

- 双引号 `"..."` 与单引号 `'...'` 语义完全一致，且**只能写在一行内**；需要换行请写 `\n`，直接换行是编译错误；
- 反引号 `` `...` `` 是唯一允许跨行的字符串写法。

历史上的 `string`/`str` 基本字符串类型已移除：写 `string s = 'x'` 或 `str s = 'x'` 会得到编译错误
`'string' type has been removed, use 'String' instead`，请改用 `String`。

### 4.2 数值转字符串

```cang
String numberText = String!$(123)
String numberObject = new String(numberText)   // 显式包装（兼容写法）
```

`String!$(expr)` 把数值转换为其字符串表示（转换总是成功，`String$(expr)` 等价）；
`new String(...)` 仍可用作显式包装。

### 4.3 字符串比较

`String` 支持 `==` 和 `!=`，按内容比较：

```cang
String a = "hello"
String b = "hello"

bool same = a == b
bool different = a != "world"
```

### 4.4 字符串常量池

字符串字面量由编译器放入 LLVM 全局常量区，相同文本可以复用常量。字符串是不可变的，拼接会生成新的字符串缓冲区。

### 4.5 转义序列

**双引号 `"..."` 与单引号 `'...'`** 共用同一套转义：

| 转义 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\"` | 双引号（单引号串中同样可用） |
| `\'` | 单引号 |
| `\0` | 空字节 |

```cang
Stdout.println("tab:[a\tb]")
Stdout.println("换行：\n下一行")
Stdout.println("路径：C:\\tmp\\x")
String t = 'a\tb'          # 单引号串同样支持转义
```

**双引号/单引号不能跨行**：`"..."` 与 `'...'` 中直接换行，或写 `\` 后换行（续行），都会在编译期报错；
需要换行只能使用转义 `\n`。只有反引号 `` `...` `` 允许写真实换行。

**反引号 `` `...` ``（多行字符串）** 支持 `\n`、`\t`、`\r`、`\\`、`` \` `` 与续行；
内容本身可直接写真换行。集合略小：**`\"` 在反引号串中是编译错误**
（`"` 无需转义，直接写即可）。

注意：

- **未知转义一律编译错误**（如 `\d`、`\x`、反引号内的 `\"`），不会静默丢掉反斜杠；
- 反引号串**不是**字节级 raw——`\n` 仍会解析成换行，它只是可跨行的字符串。
