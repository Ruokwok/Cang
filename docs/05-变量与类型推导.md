# 变量与类型推导

> 返回 [文档索引](README.md)

## 要点
- 显式类型声明与 var 类型推导
- 数组变量的元素类型跟踪
- 作用域与生命周期


显式类型声明：

```cang
int count = 10
String message = "ok"
```

使用 `var`：

```cang
var count = 10
var message = "hello"
var raw = 'hello'
```

`var` 只能根据初始化表达式推导：

```cang
var x = 1              # int
var y = 1.5            # double
var z = true           # bool
var s = "text"        # String
var r = 'text'         # str
```
