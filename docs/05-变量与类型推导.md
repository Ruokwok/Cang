# 变量与类型推导

> 返回 [文档索引](README.md)

## 要点
- 显式类型声明与 `var` 类型推导
- `var` 必须有初始化器；不能从 `null`、空数组字面量推导
- 局部变量按块作用域，内层块可遮蔽外层同名变量
- `final` 局部变量不可重新赋值

### 5.1 显式声明

```cang
int count = 10
String message = "ok"
double ratio = 1.5
bool enabled = true
```

类型写在变量名前面。数组、泛型和类类型同样可以显式声明：

```cang
int[] values = [1, 2, 3]
Pair<int, String> p = new Pair<>(1, "one")
Point origin = new Point(0, 0)
```

### 5.2 var 类型推导

`var` 根据初始化表达式推导类型，只能用于局部变量；字段必须写显式类型。

```cang
var count = 10          # int
var ratio = 1.5         # double
var enabled = true      # bool
var message = "text"    # String
var shortText = 'text'  # String
```

规则：

- `var` **必须带初始化器**：`var x` 会报 `var requires initializer`；
- 不能从 `null` 推导：`var x = null` 会报错，需写成 `String x = null`；
- 不能从空数组字面量推导：`var a = []` 会报错，需写成 `int[] a = []`；
- 类型在声明时确定，之后不能赋成不兼容的类型；
- `var` 不能替代需要显式类型实参的 diamond：`var p = new Pair<>()` 无法推断，需写 `Pair<int, String> p = new Pair<>()`。

### 5.3 数组与泛型

数组字面量会推导出元素类型和数组类型：

```cang
var numbers = [1, 2, 3]        # int[]
var names = ["a", "b"]         # String[]
var matrix = [[1, 2], [3, 4]]  # int[][]
```

有显式类型实参的泛型构造也可以推导：

```cang
var p = new Pair<String, int>("two", 2)   # Pair<String, int>
```

数组元素类型规则见 [数组](13-数组.md)，泛型规则见 [泛型](12-泛型.md)。

### 5.4 作用域与遮蔽

局部变量属于所在的块，离开块后不可见：

```cang
int x = 1
if (true) {
    int y = 2       # 只在 if 块内可见
    Stdout.println(x + y)
}
# Stdout.println(y) # 编译错误：未定义变量
```

内层块可以声明同名变量遮蔽外层变量：

```cang
int x = 1
if (true) {
    int x = 2       # 遮蔽外层 x
    Stdout.println(x)   # 2
}
Stdout.println(x)       # 1
```

lambda / `thread { }` / `coroutine { }` 按值捕获外部变量，捕获规则与赋值限制见
[函数对象与 lambda](10-函数对象与lambda.md)。

### 5.5 final

`final` 局部变量在初始化后不能重新赋值：

```cang
final int value = 10
# value = 20       # 编译错误：Cannot assign to final variable 'value'
```

字段和方法的 `final` 规则见 [继承与多态](14-继承与多态.md)。
