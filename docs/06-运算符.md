# 运算符

> 返回 [文档索引](README.md)

## 要点
- 算术、比较、逻辑运算与优先级
- 三目表达式 cond ? a : b
- 逻辑短路 && / || 单次求值
- 类型转换：`Type!$(expr)` 强制（失败报错）与 `Type$(expr)` 安全（失败返回 null/默认值）


### 6.1 算术运算

```cang
int a = 10 + 3
int b = 10 - 3
int c = 10 * 3
int d = 10 / 3
int e = 10 % 3
double f = 10 // 3       # 浮点除法
```

### 6.2 比较运算

```cang
x == y
x != y
x < y
x <= y
x > y
x >= y
```

字符串只支持可靠的 `==` 和 `!=` 内容比较。

### 6.3 逻辑运算

```cang
bool result = a && b
bool other = a || b
bool inverse = !result
```

### 6.4 三目表达式

```cang
int max = a > b ? a : b
```

### 6.5 类型转换

转换统一写作 `目标类型 !$ ( 表达式 )`（强制）或 `目标类型 $ ( 表达式 )`（安全）。
`$` 是转换标记，不再是歧义的方法调用写法。

```cang
Apple a = Apple!$(fruit)     # 强制向下转型：失败抛运行时可捕获错误
Apple b = Apple$(fruit)      # 安全向下转型：失败返回 null
int n = int!$(10000L)        # 强制窄化：溢出报错
int m = int$(3000000000L)    # 安全窄化：溢出返回 0
```

语义：

| 写法 | 成功 | 失败 |
|---|---|---|
| `Type!$(expr)` | 转换结果 | 运行时错误（可被 `try/catch` 捕获） |
| `Type$(expr)` | 转换结果 | 引用类型 → `null`；基本类型 → 默认值（`0` / `false`） |

转换规则：

- **对象向下转型**（类名目标）：运行时按 typeId 校验；目标类及其具体子类通过。
  `null` 转 `null`；`Apple$(someFruit)` 类型不匹配返回 `null`，`Apple!$(...)` 抛错。
- **数值窄化**（`long`→`int`、`int`→`byte`、浮点→整数、`double`→`float`）：
  值超出目标范围视为失败。浮点转整数还检查 `NaN`（同样算失败）。
- **拓宽**永不失败：`int`→`long`、整数→浮点、`float`→`double` 直接转换
  （精度可能降低，但不是溢出）。
- **字符串转数字**（`int!$("42")`）：要求整串是一个完整数字，含多余字符或为空即失败；
  失败时强制版报错、安全版返回默认值。
- **数字转 `String`**（`String!$(123)`）：总是成功，得到其十进制文本。

> 旧写法 `Apple(fruit)`、`int(expr)`、`String(expr)` 已全部移除，出现时会提示改用 `!$` / `$`。
