# 运算符

> 返回 [文档索引](README.md)

## 要点
- 算术、比较、逻辑运算与优先级
- 三目表达式 cond ? a : b
- 逻辑短路 && / || 单次求值


### 6.1 算术运算

```cang
int a = 10 + 3
int b = 10 - 3
int c = 10 * 3
int d = 10 / 3
int e = 10 % 3
double f = 10 // 3       # 浮点除法
```

### 6.2 比较运算

```cang
x == y
x != y
x < y
x <= y
x > y
x >= y
```

字符串只支持可靠的 `==` 和 `!=` 内容比较。

### 6.3 逻辑运算

```cang
bool result = a && b
bool other = a || b
bool inverse = !result
```

### 6.4 三目表达式

```cang
int max = a > b ? a : b
```
