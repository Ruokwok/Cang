# 条件语句

> 返回 [文档索引](README.md)

## 要点
- if / else 分支
- switch / case / default（支持多 case 与 fall-through）
- 条件表达式为 bool

### 7.1 if / else

```cang
if (score >= 60) {
    Stdout.println("pass")
} else {
    Stdout.println("fail")
}
```


---

### 7.5 switch

```cang
switch (value) {
    case 1:
        Stdout.println("one")
    case 2:
        Stdout.println("two")
    default:
        Stdout.println("other")
}
```
