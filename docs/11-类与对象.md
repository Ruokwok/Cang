# 类与对象

> 返回 [文档索引](README.md)

## 要点
- class Name(参数) 即构造器，参数即字段
- 实例方法、静态方法、字段与 this
- 单继承 : Parent(args)；每文件可多类，入口类第一


### 10.1 定义类

```cang
class Point(int x = 0, int y = 0)
```

创建对象：

```cang
Point p = new Point(10, 20)
```

### 10.2 实例方法

```cang
class Counter(int value = 0)

func int get() {
    return this.value
}
```

调用：

```cang
Counter c = new Counter(10)
Stdout.println(c.get())
```

### 10.3 静态方法

```cang
class MathUtil()

static func int doubleValue(int x) {
    return x * 2
}
```

调用：

```cang
Stdout.println(MathUtil.doubleValue(21))
```

静态方法必须使用：

```cang
static func ReturnType method(Args...) { ... }
```

### 10.4 继承

```cang
class Animal(String name = "animal")
class Dog(String name = "dog") : Animal(name)
```

Cang 当前只支持单继承，不支持多继承。
## 私有构造器（类名 _ 前缀）

类名以 _ 开头表示**私有构造**：外部不能 
ew，只能在**该类自己的静态或实例方法内**实例化
（与字段/方法的 _ 私有惯例一致）——典型用法是静态工厂：

```cang
class Main()
var s = _Server.create("alpha")     # 经工厂创建
Stdout.println(s.name)              # alpha
var bad = new _Server("x")          # 编译错误：private constructor

class _Server(String name = "anon")
static func _Server create(String n) {
    return new _Server(n)           # 本类静态方法内：允许
}

func _Server copy() {
    return new _Server(this.name)   # 本类实例方法内：允许
}
```

- 外部 
ew _Server(...) 报：
  Class '_Server' has a private constructor (leading '_'); new is only allowed inside the class itself；
- 入口类的顶层语句视为该类自己的代码（顶层 
ew 自己允许）；
- 类型注解、返回值、字段使用私有类**不受限制**（限制只在 
ew 点）。
