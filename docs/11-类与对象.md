# 类与对象

> 返回 [文档索引](README.md)

## 要点
- class Name(参数) 即构造器，参数即字段
- 实例方法、静态方法、字段与 this
- 单继承 : Parent(args)；每文件可多类，入口类第一


### 10.1 定义类

```cang
class Point(int x = 0, int y = 0)
```

创建对象：

```cang
Point p = new Point(10, 20)
```

### 10.2 实例方法

```cang
class Counter(int value = 0)

func int get() {
    return this.value
}
```

调用：

```cang
Counter c = new Counter(10)
Stdout.println(c.get())
```

### 10.3 静态方法

```cang
class MathUtil()

static func int doubleValue(int x) {
    return x * 2
}
```

调用：

```cang
Stdout.println(MathUtil.doubleValue(21))
```

静态方法必须使用：

```cang
static func ReturnType method(Args...) { ... }
```

### 10.4 继承

```cang
class Animal(String name = "animal")
class Dog(String name = "dog") : Animal(name)
```

Cang 当前只支持单继承，不支持多继承。
## 私有构造器（类名 `_` 修饰符）

类名前的 `_` 是**修饰符，不是名字的一部分**：真实类名、命名空间、类型注解与 import 后使用的
名字都**不带 `_`**。`_` 与类名之间可以有空格（`class _ Server` 与 `class _ Server` 等价）。

```cang
class Main()
var s = Server.create("alpha")      # 类型是 Server（不带 _）
Stdout.println(s.name)              # alpha
var bad = new Server("x")           # 编译错误：private constructor

class _ Server(String name = "anon")   # 修饰符 _ + 空格 + 类名 Server
static func Server create(String n) {
    return new Server(n)            # 本类静态方法内：允许
}

func Server copy() {
    return new Server(this.name)    # 本类实例方法内：允许
}
```

- 两种声明形态等价：`class _Server(...)`、`class _ Server(...)`——都声明私有类 `Server`；
- 外部 `new Server(...)` 报：
  `Class 'Server' has a private constructor; new is only allowed inside the class itself`；
- import 路径按**文件**写（如 `Server.cang` → `import cc/ruok/Server`），得到的类型名仍是 `Server`；
- 入口类的顶层语句视为该类自己的代码（顶层 `new` 自己允许）；
- 类型注解、返回值、字段使用私有类**不受限制**（限制只在 `new` 点）——静态工厂是标准出口。

### 完整单例模式

私有构造 + 静态字段 + 静态工厂即可在纯 Cang 中实现单例：

```cang
class Main()
var a = Db.get()
var b = Db.get()
Stdout.println(a == b)        # true —— 同一实例（引用比较）
Stdout.println(Db.instances)  # 1 —— 静态字段限定读

class _ Db(String name = "db", int count = 0)
static Db instance = null     # 静态字段：类内裸名读写，类外 Db.instance 限定读
static int instances = 0      # 常量字面量初始值在全局初始化器中生效

static func Db get() {
    if (instance == null) {   # 对象 == null 判空可用
        instance = new Db()    # 本类内 new —— 私有构造放行
        instances = instances + 1
    }
    return instance
}
```

- 静态字段支持**常量字面量**初始化（数值/bool/null/String）；复杂表达式初始化暂不支持（落到默认值）；
- 对象之间支持 `==` / `!=` **引用比较**；`对象 == null` 判空可用；顺序比较（`<` 等）仅限数值；
- 实例字段仍走**构造参数**模型（`count = 0` 即字段）。
