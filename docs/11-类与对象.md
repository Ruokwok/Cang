# 类与对象

> 返回 [文档索引](README.md)

## 要点
- `class Name` 无括号；字段在类体声明，构造方法固定名 `init`（私有 `_init`）
- 实例方法、静态方法、字段与 this
- 单继承 `: Parent`（父类参数经 `super(...)` 传递）；**一个文件一个类**


### 11.1 定义类

字段在类体声明，构造方法写成 `init(...)`：

```cang
class Point
    int x = 0;
    int y = 0;

    init(int x, int y) {
        this.x = x;
        this.y = y;
    }
```

创建对象：

```cang
Point p = new Point(10, 20)
```

- 字段声明处的值是默认值；每次构造都在构造 body 之前按声明顺序初始化（先 `super()`，后字段，再 body）；
- 不写任何构造方法时默认 `init() {}`（零参）；
- `init` 的参数支持重载或默认值，二者不能同时使用（与方法一致）。

### 11.2 实例方法

```cang
class Counter
    int value = 0;

    init(int value) {
        this.value = value;
    }

    func int get() {
        return this.value
    }
```

调用：

```cang
Counter c = new Counter(10)
Stdout.println(c.get())
```

### 11.3 静态方法

```cang
class MathUtil

static func int doubleValue(int x) {
    return x * 2
}
```

调用：

```cang
Stdout.println(MathUtil.doubleValue(21))
```

静态方法必须使用：

```cang
static func ReturnType method(Args...) { ... }
```

### 11.4 继承

```cang
# Animal.cang
class Animal
    String name = "animal";

    init(String name) {
        this.name = name;
    }
```

```cang
# Dog.cang（另一文件）
import Animal

class Dog : Animal
    init(String name) {
        super(name);
    }
```

- 只支持单继承，不支持 `class A : B, C`；多级链合法（`RedApple : Apple`、`Apple : Fruit` 依次声明即可）；
- **一个文件一个类**：继承链跨文件，子类文件用 `import` 引入父类；
- 父类构造参数在 `init` 内用 `super(...)` 传递（与 Java 一致）；不写 `super(...)` 时隐式调用父类零参 `init()`。

### 11.5 构造方法（`init` / `_init`）

- 固定方法名 `init`，与方法一样支持重载或参数默认值（两者互斥）；
- `_init` 声明私有构造：仅本类内的 `new` 可调用；
- 一个类可以有多个 `init` 重载，`new` 按实参匹配。

### 11.6 私有构造器（`_init`）

`_init(...)` 是私有构造方法；类型名、命名空间与 import 均不带任何前缀。

```cang
# Server.cang —— 一个文件一个类
class Server
    String name = "anon";

    _init(String name) {
        this.name = name;
    }

    static func Server create(String n) {
        return new Server(n)            # 本类静态方法内：允许
    }

    func Server copy() {
        return new Server(this.name)    # 本类实例方法内：允许
    }
```

```cang
# Main.cang
import Server

class Main
    static func void main(String[] args) {
        var s = Server.create("alpha")
        Stdout.println(s.name)          # alpha
        # var bad = new Server("x")     # 编译错误：Class 'Server' has a private constructor (_init)
    }
```

- `_init` 声明的构造签名私有：类外 `new Server(...)` 编译报
  `Class 'Server' has a private constructor (_init)`；
- import 路径按**文件**写（`Server.cang` → `import Server`），类型名是 `Server`；
- 类型注解、返回值、字段使用该类型**不受限制**（限制只在 `new` 点）——静态工厂是标准出口。

### 11.7 完整单例模式

私有构造 + 静态字段 + 静态工厂即可在纯 Cang 中实现单例：

```cang
# Db.cang
class Db
    String name = "db";
    int count = 0;

    static Db instance = null     # 静态字段：类内裸名读写，类外 Db.instance 限定读
    static int instances = 0      # 常量字面量初始值在全局初始化器中生效

    _init() {
    }

    static func Db get() {
        if (instance == null) {   # 对象 == null 判空可用
            instance = new Db()    # 本类内 new —— 私有构造放行
            instances = instances + 1
        }
        return instance
    }
```

```cang
# Main.cang
import Db

class Main
    static func void main(String[] args) {
        var a = Db.get()
        var b = Db.get()
        Stdout.println(a == b)        # true —— 同一实例（引用比较）
        Stdout.println(Db.instances)  # 1 —— 静态字段限定读
    }
```

- 静态字段支持**常量字面量**初始化（数值/bool/null/String）；复杂表达式初始化暂不支持（落到默认值）；
- 对象之间支持 `==` / `!=` **引用比较**；`对象 == null` 判空可用；顺序比较（`<` 等）仅限数值；
- 实例字段在**类体**声明（`int count = 0` 即字段与默认值），`init` 内赋值覆盖默认。

### 11.8 类字面量（`Apple.class`）

用 `类名.class` 获取运行时类信息对象 `Class`，同一个类全局单例：

```cang
class Main
    static func void main(String[] args) {
        Class c = Apple.class
        Stdout.println(c.getName())          # Apple
        Stdout.println(c == Apple.class)     # true
        Stdout.println(c.getSuperclass().getName())
    }
```

`Class` 还提供 `getSimpleName()`、`isAssignableFrom(Class)` 与 `toString()`，并支持
`String.class`、`int.class` 等写法。完整 API 与限制见 [Class 类信息](libs/Class.md)。

需要按字段名读取对象字段时，使用 [`Field` 字段反射](libs/Field.md)（`new Field(obj).getInt("x")`，只读）。
