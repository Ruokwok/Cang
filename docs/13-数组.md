## 要点
- T[] / T[N] / 多维数组与字面量 [1,2,3]
- 运行时长度 new T[expr]、元素赋值与越界检查
- length() 与数组 null 检查


### 11.1 数组声明

```cang
int[10] fixed = []          # 固定长度 10，零填充
int[] values = [1, 2, 3]    # 长度从字面量推导
var numbers = [1, 2, 3]     # 类型和长度都推导
```

多维数组：

```cang
int[][] matrix = [[1, 2], [3, 4]]
int[2][] rows = [[1, 2], [3, 4]]
```


### 11.2 访问和赋值

```cang
int[] values = [1, 2, 3]
Stdout.println(values[0])
values[1] = 20
```

嵌套数组：

```cang
int[][] matrix = [[1, 2], [3, 4]]
Stdout.println(matrix[0][1])
matrix[1][0] = 30
```

编译器会检查元素类型并在运行时检查下标边界。

### 11.3 length()

数组通过 `.length()` 获取长度：

```cang
int[] values = [1, 2, 3]
Stdout.println(values.length())       # 3

int[][] matrix = [[1, 2], [3]]
Stdout.println(matrix.length())       # 2
Stdout.println(matrix[0].length())    # 2
```

数组长度存储在数组内存头部，`length()` 返回 `int`。
