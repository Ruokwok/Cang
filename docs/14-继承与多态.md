# 继承与多态

> 返回 [文档索引](README.md)

## 要点
- Object 根类、类型 ID 动态分派与 override
- like 运算符做 instanceof 检查
- final 类/方法/常量与不可重写规则


所有普通类默认继承 `Object`。

```cang
class User(String name = "guest")
```

可以显式继承：

```cang
class Animal(String name = "animal")
class Dog(String name = "dog") : Animal(name)
```

当前支持：

- 单继承；
- 父类构造参数；
- `like` 类型判断；
- 基于类型 ID 的动态方法分派。

不支持多继承。

---

## 20. final

变量常量：

```cang
final int value = 10
value = 20       # 编译错误
```

函数不可重写：

```cang
final func void run() {
    Stdout.println("run")
}
```

子类不能覆盖 final 方法。

## 抽象类与抽象方法

`cang
class Main()
Shape s = new Circle(2.0)
Stdout.println(s.area())      # 12.566360（动态分派到 Circle.area）

abstract class Shape(String name = "")
abstract func double area()                 # 无方法体，子类必须实现
func String describe() {                    # 普通方法可有默认实现
    return this.name + " ready"
}

class Circle(double r = 1.0) : Shape("circle")
func double area() {
    return 3.14159 * this.r * this.r
}
``n
规则：

- `abstract class` 不能被实例化（`Cannot instantiate abstract class`）；
- `abstract func` 无方法体（写了 body 编译报错）、不能 `static`、不能与 `native` 组合；
- 非 abstract 类必须实现继承链上的全部抽象方法（按**方法名+参数签名**匹配），否则编译报错 `must implement abstract method ... implement it or declare the class abstract`；父类已有具体实现时子类可不覆盖；
- 非 abstract 类不能声明 `abstract func`；
- 调用走动态分派：抽象类型的分派臂被剔除（abstract 类不可能是运行时实例），编译器不为抽象方法生成函数体。
