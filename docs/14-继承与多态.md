# 继承与多态

> 返回 [文档索引](README.md)

## 要点
- Object 根类、类型 ID 动态分派与 override
- like 运算符做 instanceof 检查
- final 类/方法/常量与不可重写规则


所有普通类默认继承 `Object`。

```cang
class User(String name = "guest")
```

可以显式继承：

```cang
class Animal(String name = "animal")
class Dog(String name = "dog") : Animal(name)
```

当前支持：

- 单继承；
- 父类构造参数；
- `like` 类型判断；
- 基于类型 ID 的动态方法分派。

不支持多继承。

---

## 20. final

变量常量：

```cang
final int value = 10
value = 20       # 编译错误
```

函数不可重写：

```cang
final func void run() {
    Stdout.println("run")
}
```

子类不能覆盖 final 方法。
