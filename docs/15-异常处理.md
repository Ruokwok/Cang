# 异常处理

> 返回 [文档索引](README.md)

## 要点
- try / catch / finally：同函数控制流 + 跨函数异常回退
- throw new Error(...)；catch 类型须为 Error 或子类
- 运行时错误（空指针/越界/除零）可被 try 捕获
- 异常跨函数传播：函数内抛出（或发生可捕获运行时错误）而本函数没有 catch 时，异常逐帧向调用方回退，直到调用链上最近的 try 被接住；全部逃逸则按未捕获处理

### 15.1 try/catch

`try/catch/finally` 与 `throw` 已可用，捕获的对象必须是 `cang/lang/Error` 或其子类。`Error` 会在引用时自动加载，显式 import 可选：

```cang
import cang/lang/Error

class Main
    static func void main(String[] args) {
        try {
            throw new Error("boom")
        } catch (Error e) {
            Stdout.println(e.message)
        } finally {
            Stdout.println("done")
        }
    }
```

未捕获异常会打印错误消息和位置并以退出码 1 结束：

```cang
import cang/lang/Error

class Main
    static func void main(String[] args) {
        throw new Error("loud failure")
    }
```

输出：

```text
error: loud failure
  at program.cang:4
```

自定义异常继承 `Error`（**一个文件一个类**，子类文件 `import` 父类）：

```cang
# MyError.cang
import cang/lang/Error

class MyError : Error
    init(String message) {
        super(message);
    }
```

```cang
# Main.cang
import cang/lang/Error
import MyError

class Main
    static func void main(String[] args) {
        try {
            throw new MyError("sub")
        } catch (MyError e) {
            Stdout.println(e.message)
        }
    }
```

`Error` 的字段：

- `message`：`String`，错误消息；
- `stack`：`String[]`，预留的堆栈信息数组（当前运行时尚未自动填充）。

### 15.2 异常跨函数传播

和 Java 一样，`throw` 不必与本函数的 `try` 在同一控制流内：被调用方法抛出的异常会回退到调用方最近的 `try`，包括运行时错误（空指针、越界、除零、反射 `Field` 访问失败等）：

```cang
import cang/lang/Error

class Main
    static func void loud(int x) {
        throw new Error("boom-" + x)
    }

    static func int deep(int x) {
        Main.loud(x)        # 深处抛出
        return 0
    }

    static func void main(String[] args) {
        try {
            Main.deep(1)        # 上两层被这里的 catch 接住
            Stdout.println("not reached")
        } catch (Error e) {
            Stdout.println("caught: " + e.message)   # caught: boom-1
        }
    }
```

传播路径上经过的 `finally` 都会先执行。实现方式是标志位回退（非 `invoke`/`landingpad`）：无本地 catch 的 `throw` 设置待处理标志并从当前函数返回，每个用户函数调用点之后检查该标志——本函数有 `try` 就转入其 catch，否则本函数也原样返回，继续向上一层回退。

当前限制：

- 同一 `try` 只支持一个 `catch`；
- `catch` 类型必须是 `Error` 或其子类，否则编译错误；
- `finally` 会在异常传播前执行；
- 异常不跨线程：线程内抛出且未被捕获时，打印错误并以退出码 1 结束进程；
- 跨函数传播期间调用方的返回值不可用（被丢弃），不会参与后续运算。
